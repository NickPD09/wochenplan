KAPITEL 3Mechanische Pendel

Federpendel

f = 12π√km
T = 2π√mk

Hooke: F = −k·Δx. m×4 ⇒ T×2. Härtere Feder ⇒ T kleiner.

Fadenpendel (mathematisch)

T = 2π√lg
k = m·gl

Nur für kleine Auslenkungen harmonisch (cos α ≈ 1). Unabhängig von m, weil Rückstellkraft ∝ m (m kürzt sich).

Dreh-/Torsionspendel

T = 2π√Ik*

Statt m → Trägheitsmoment I = Σ r²·m. Statt F → Moment M. k* = −M/φ (Winkelrichtgröße). M = I·α.

Physisches Pendel

T = 2π√Im·g·s

Starrer Körper, s = Abstand Drehachse–Schwerpunkt. Kleine Winkel: sin φ ≈ φ (22,5° → 0,39 vs 0,38).

Schwerelos: Fadenpendel schwingt nicht (g = 0). Federpendel schwingt gleich wie auf der Erde (k, m unverändert).
Am schnellsten: Fadenpendel auf dem Jupiter (größtes g ⇒ kleinstes T).

KAPITEL 5Dämpfung, Selbsterregung, Resonanz

Freie & gedämpfte Schwingung

Freie Schwingung: einmal anstoßen, dann sich selbst überlassen → schwingt mit Eigenfrequenz f₀. Jede reale freie Schwingung ist gedämpft. Viskose Dämpfung: Reibung ∝ v.

Energie wird im richtigen Moment nachgeliefert, gesteuert vom Schwinger selbst (Rückkopplung). Beispiele: Pendeluhr, Schaukel.

KAPITEL 6Überlagerung von Schwingungen

Superpositionsprinzip: Auslenkungen werden einfach addiert: y = y₁ + y₂
y₁ = r₁·sin(ω₁t)    y₂ = r₂·sin(ω₂t + Δφ)

Ergebnis ist periodisch, aber nicht mehr sinusförmig (anharmonisch).

KAPITEL 7Wellen: Entstehung & Beschreibung

Welle = Schwingung, die sich durch Kopplung von Teilchen zu Teilchen ausbreitet. Mechanische Wellen brauchen ein Medium, elektromagnetische (Licht, Radio) nicht.

Wichtig: Eine Welle transportiert Energie, aber keine Masse. Jedes Teilchen schwingt nur um seine eigene Ruhelage.

Transversalwelle (Querwelle)

Schwingung quer zur Ausbreitung. Seil, Wasseroberfläche, Licht.

Longitudinalwelle (Längswelle)

Schwingung längs zur Ausbreitung. Verdichtungen & Verdünnungen. Schall in Luft, Feder.

Simulation · Transversal vs. Longitudinal
c = λ·f     λ = c·T

In der Zeit T läuft ein Wellenberg genau eine Wellenlänge λ weiter.

  • λ = Abstand zweier nächster Teilchen im gleichen Schwingungszustand (räumliche Periode)
  • Schnelle = Geschwindigkeit eines Teilchens um seine Ruhelage ≠ c!
  • c hängt von der Kopplung ab: cLuft < cWasser < cEisen

Wellengleichung

y(t, x) = r·sin ω(t − xc)
  • x = const → Schwingung eines Teilchens (zeitliche Periode T)
  • t = const → Momentanbild der Welle (räumliche Periode λ)
Merke: f bestimmt der Erreger (bleibt konstant). c und λ bestimmt das Medium (können sich ändern). Amplitude kann durch Dämpfung sinken.

KAPITEL 8Schallwellen

  • Longitudinalwellen (Dichtewellen) gehen in festen, flüssigen und gasförmigen Stoffen (Volumselastizität).
  • Transversalwellen nur in Festkörpern (Formelastizität) + Flüssigkeitsoberfläche.
  • Im Festkörper: clongitudinal > ctransversal

KAPITEL 9Ausbreitung von Wellen

Wellenfronten & Wellenstrahlen

  • Wellenfront: alle Punkte gleicher Phase. Abstand benachbarter Fronten = λ.
  • Wellenstrahl: Ausbreitungsrichtung, steht ⟂ auf Wellenfront.
  • Punktförmiger Erreger → Kreis-/Kugelwelle (Strahlen radial). Gerader Erreger → ebene Welle (Strahlen parallel).
  • Kugelwelle: Energie pro Fläche ∝ 1/r². Weit weg ≈ ebene Welle (Sonnenlicht).

Interferenz zweier Wellen

Gangunterschied Δx = Unterschied der Laufwege.

Δx = k·λkonstruktiv: Berg trifft Berg → Maximum
Δx = (2k + 1)·λ2destruktiv: Berg trifft Tal → Minimum

Kohärent = gleiche Frequenz + konstanter Gangunterschied ⇒ stabiles Interferenzmuster.

Huygens'sches Prinzip

Jeder Punkt einer Wellenfront ist Ausgangspunkt einer Elementarwelle. Die neue Wellenfront ist die Einhüllende aller Elementarwellen.

Beugung

Welle dringt in den geometrischen Schattenraum ein. Je näher Spaltbreite an λ, desto stärker. Spalt ≤ λ ⇒ Kreiswelle hinter dem Spalt.

Reflexion

α = β  (Einfallswinkel = Reflexionswinkel, jeweils zum Lot)
Wellefestes Endefreies Ende
Transversal (Seil)Berg → Tal, Phasensprung Δφ = πBerg → Berg, kein Sprung
Longitudinal (Schall)Verdichtung → Verdichtung, Schnelle springt um π (schallhart)Verdichtung → Verdünnung, Schnelle bleibt (schallweich)

Echo: direkter und reflektierter Schall getrennt hörbar. Nachhall: nicht trennbar, wichtig für Raumklang.

Brechung (Snellius)

sin αsin β = c₁c₂ = λ₁λ₂

f bleibt gleich, c und λ ändern sich. Keine Brechung bei α = 0 oder c₁ = c₂. Langsameres Medium ⇒ zum Lot hin.

Rechner · Brechung

Fermat'sches Prinzip

Ein Strahl nimmt von A nach B immer den Weg mit der kürzesten Zeit. Daraus folgen Reflexions- und Brechungsgesetz.

a = 1 m, b = 2 m: l₁ = 1 + √5 = 3,23 m   l₂ = 2√2 = 2,83 m (α = β, kürzester Weg)

KAPITEL 10Dopplereffekt

Sender und Empfänger bewegen sich relativ zueinander ⇒ Empfänger hört andere Frequenz. (Christian Doppler, Österreicher.)

Sender bewegt (v)

f = f₀1 ∓ v/c

− : nähert sich (f ↑)   + : entfernt sich (f ↓)
λ = λ₀ − v·T₀, c bleibt gleich.

Empfänger bewegt (v)

f = f₀·(1 ± v/c)

+ : nähert sich (f ↑)   − : entfernt sich (f ↓)
λ bleibt, c' = c ± v.

Nicht symmetrisch! v = c/2: Empfänger → 1,5·f₀ / 0,5·f₀. Sender → 2·f₀ / ⅔·f₀.

Überschall (v > c): Wellenfronten überholen sich → Mach'scher Kegel → Überschallknall (Flugzeug, Geschoss, Peitsche, Bugwelle).

Gilt für alle Wellen: Verkehrsradar, Rotverschiebung von Licht.

Wellen (Arbeitsblatt)

Wie ändert sich λ, wenn f bzw. c verdoppelt wird?
λ = c/f
f × 2 ⇒ λ halbiert
c × 2 ⇒ λ verdoppelt
Ozeanwelle: λ = 300 m, T = 15 s. c?
c = λ/T = 300/15 = 20 m/s
Wellenwanne: c = 20 cm/s, λ = 2 cm. f?
f = c/λ = 20/2 = 10 Hz
Ö3: f = 88,5 MHz, c = 3·10⁸ m/s. λ?
λ = c/f = 3·10⁸ / 88,5·10⁶ = 3,39 m
Schall: c = 330 m/s, f = 1000 Hz. λ?
λ = 330/1000 = 0,33 m
Doppler: Fußgänger hört 3·f₀. Wie schnell ist das Fahrzeug?
3f₀ = f₀/(1 − v/c) ⇒ 1 − v/c = ⅓
v = ⅔·c
