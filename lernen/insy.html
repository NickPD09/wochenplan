So gehst du vor

  1. Nomen und Verben im Text markieren.
  2. Abhaken, was schon im Modell ist. Nur Neues dazuzeichnen.
  3. Jede Beziehung von beiden Seiten lesen: „Ein A hat wie viele B?“ und „Ein B hat wie viele A?“
  4. Jeder neuen Entität einen Schlüssel geben.
  5. Beziehungsattribute an die Raute hängen.
1 + 1 → 1:1  ·  1 + mehrere → 1:n  ·  mehrere + mehrere → m:n

02Umwandlungsregeln

Schreibweise: Tabelle(PK, Attribut, #FK). Primärschlüssel unterstrichen, Fremdschlüssel mit #.

Merksatz: 1:n → FK auf die n-Seite. m:n → neue Tabelle. Attribute der Beziehung kommen dorthin, wo die Beziehung landet.

03Beispiele zum Durchklicken

Lies den Text, schau dir das ER-Modell an und überleg dir die Tabellen. Dann deckst du sie Schritt für Schritt auf.

04Übungen wie im Test

05Typische Fehler

  • FK bei 1:n auf die 1-Seite gesetzt. Er gehört auf die n-Seite.
  • Bei m:n die Zwischentabelle vergessen.
  • Beziehungsattribut (Note, Menge, Datum) in eine Entität gesteckt.
  • Bei einer schwachen Entität den FK nicht in den PK genommen.
  • FK auf eine schwache Entität nur mit einem Teil des Schlüssels.
  • Kardinalität nur von einer Seite gelesen.
  • Neue Entität ohne Schlüssel.
